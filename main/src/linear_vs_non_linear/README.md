* Linear models just have bunch of linear layers combined via matrix multiplication.
* They can't bend the vector space and hence can-not fit complex data
* For example we can never make the model fit a hyperbola/parabola type of curve just with linear models
* Having a non-linearity like tanh/ReLU/GELU would enable this, they allow us to bend the vector space to represent complex curvatures
* the notebook shows an example of this
